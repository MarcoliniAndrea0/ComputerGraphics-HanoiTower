Definizioni di macro comuni, utility di debug e gestione dell\textquotesingle{}esportazione DLL.

Macro per la gestione dell\textquotesingle{}esportazione e importazione di simboli nelle librerie dinamiche (DLL). 

Questa macro gestisce automaticamente l\textquotesingle{}esportazione e importazione dei simboli quando si compila una libreria dinamica su Windows\+:


\begin{DoxyItemize}
\item {\bfseries{Su Windows (\+\_\+\+WINDOWS definito)}}\+:
\begin{DoxyItemize}
\item Se SIMPLEDYNLIB\+\_\+\+EXPORTS è definito (durante la compilazione della DLL)\+: espande a \+\_\+\+\_\+declspec(dllexport) per esportare i simboli
\item Altrimenti (durante l\textquotesingle{}uso della DLL)\+: espande a \+\_\+\+\_\+declspec(dllimport) per importare i simboli
\end{DoxyItemize}
\item {\bfseries{Su altre piattaforme}} (Linux, mac\+OS)\+: la macro è vuota, poiché questi sistemi gestiscono i simboli delle librerie condivise in modo diverso.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Questa macro deve essere usata prima della dichiarazione di ogni classe o funzione che deve essere visibile dall\textquotesingle{}esterno della DLL.
\end{DoxyNote}
