\doxysubsection{Detailed Description}
Gestisce una lista ordinata di nodi e le loro matrici di trasformazione per il rendering. 

La classe \doxylink{classList}{List} è responsabile della creazione e gestione di una lista "{}flat"{} (appiattita) di tutti i nodi da renderizzare nella scena, insieme alle loro matrici di trasformazione globali precalcolate.

Funzionalità principali\+:
\begin{DoxyItemize}
\item {\bfseries{Traversal del grafo}}\+: Attraversa ricorsivamente il grafo della scena per raccogliere tutti i nodi renderizzabili
\item {\bfseries{Calcolo matrici globali}}\+: Precalcola le world matrices per ogni nodo moltiplicando le trasformazioni gerarchiche
\item {\bfseries{Ordinamento per priorità}}\+: Riordina i nodi secondo la priorità di rendering (Camere → Luci → \doxylink{classMesh}{Mesh})
\item {\bfseries{Ottimizzazione}}\+: Evita il ricalcolo delle trasformazioni durante il rendering
\end{DoxyItemize}

Il sistema di priorità garantisce che\+:
\begin{DoxyEnumerate}
\item Le telecamere vengano processate per prime
\item Le luci vengano configurate prima di renderizzare gli oggetti
\item Le mesh vengano renderizzate per ultime
\end{DoxyEnumerate}

Genera ricorsivamente una lista flat di tutti i nodi renderizzabili. 

Genera una lista di nodi e le loro matrici di trasformazione globale per il rendering.

Attraversa l\textquotesingle{}intero grafo della scena a partire dal nodo radice, visitando ricorsivamente tutti i figli e calcolando le matrici di trasformazione globali (world matrices) per ciascun nodo.

Il traversal è di tipo depth-\/first (profondità prima) e\+:
\begin{DoxyItemize}
\item Raccoglie ogni nodo visitato
\item Calcola la world matrix moltiplicando la local matrix con quella del parent
\item Continua ricorsivamente per tutti i figli
\end{DoxyItemize}

Renderizza tutti gli oggetti nella lista in ordine. 

Renderizza tutti gli oggetti nella lista di rendering.

Itera attraverso la lista ordinata di nodi e invoca il metodo \doxylink{classList_a88bc9bad52374db6df5b46036a77bb47}{render()} di ciascuno, passando la view matrix calcolata dalla camera.

Il processo di rendering\+:
\begin{DoxyEnumerate}
\item Per ogni nodo nella lista (già ordinata per priorità)
\item Calcola la view matrix moltiplicando inversa\+Camera con la world matrix
\item Chiama il metodo \doxylink{classList_a88bc9bad52374db6df5b46036a77bb47}{render()} del nodo con questa view matrix
\end{DoxyEnumerate}

Riordina la lista degli oggetti secondo la priorità di rendering. 

Riordina la lista degli oggetti da renderizzare in base alla priorit{\ucr}.

Ordina i nodi nella lista in base alla loro priorità per garantire un ordine corretto di rendering. L\textquotesingle{}ordinamento segue questa gerarchia\+:


\begin{DoxyEnumerate}
\item {\bfseries{\doxylink{classCamera}{Camera}}} (priorità più alta)\+: Devono essere processate per prime per configurare la view matrix
\item {\bfseries{\doxylink{classLight}{Light}}} (priorità media)\+: Devono essere configurate prima di renderizzare gli oggetti che verranno illuminati
\item {\bfseries{Altri oggetti}} come \doxylink{classMesh}{Mesh} (priorità più bassa)\+: Vengono renderizzati per ultimi usando camera e luci già configurate
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Questo metodo modifica l\textquotesingle{}ordine interno della lista. Deve essere chiamato dopo aver popolato la lista con \doxylink{classList_af69954fa434a31e038bc78e98ee6578a}{pass()} e prima di chiamare \doxylink{classList_a88bc9bad52374db6df5b46036a77bb47}{render()}.
\end{DoxyNote}
