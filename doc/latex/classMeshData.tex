\doxysubsection{Detailed Description}
Rappresenta i dati geometrici di una mesh 3D. 

La classe \doxylink{classMeshData}{Mesh\+Data} gestisce tutti i dati geometrici necessari per definire e renderizzare una mesh tridimensionale. Fornisce una struttura organizzata per memorizzare\+:


\begin{DoxyItemize}
\item {\bfseries{Vertici}}\+: Posizioni dei punti nello spazio 3D
\item {\bfseries{Facce}}\+: Definizione dei triangoli attraverso indici di vertici
\item {\bfseries{Normali}}\+: Vettori perpendicolari alle superfici per illuminazione e shading
\item {\bfseries{Coordinate UV}}\+: Mappatura 2D per l\textquotesingle{}applicazione delle texture
\end{DoxyItemize}

Caratteristiche del sistema\+:
\begin{DoxyItemize}
\item Geometria basata su triangoli (ogni faccia ha esattamente 3 vertici)
\item Supporto per normal mapping (una normale per vertice)
\item Supporto per texture mapping (coordinate UV per vertice)
\item Organizzazione efficiente dei dati per il rendering
\end{DoxyItemize}

I dati sono organizzati in modo che\+:
\begin{DoxyItemize}
\item Ogni vertice abbia un indice univoco (0, 1, 2, ...)
\item Ogni faccia faccia riferimento a 3 indici di vertici
\item Ogni vertice possa avere una normale e coordinate UV associate
\end{DoxyItemize}

\begin{DoxyNote}{Note}
La classe non gestisce direttamente VBO (Vertex Buffer Objects) Open\+GL, ma fornisce i dati in un formato facilmente utilizzabile per crearli.
\end{DoxyNote}

Restituisce la lista delle coordinate UV della mesh. 

Restituisce la lista delle coordinate UV per questa mesh.

Le coordinate UV definiscono come una texture 2D viene mappata sulla superficie 3D della mesh. Ogni coordinata UV è un vettore 2D\+:
\begin{DoxyItemize}
\item U (x)\+: Coordinata orizzontale sulla texture (0.\+0 -\/ 1.\+0)
\item V (y)\+: Coordinata verticale sulla texture (0.\+0 -\/ 1.\+0)
\end{DoxyItemize}

Tipicamente c\textquotesingle{}è una coppia di coordinate UV per ogni vertice, permettendo al rendering engine di determinare quale pixel della texture corrisponde a quale punto sulla superficie.

\begin{DoxyReturn}{Returns}
Riferimento costante al vettore di coordinate UV
\end{DoxyReturn}
\begin{DoxyNote}{Note}
Le coordinate UV sono tipicamente nel range \mbox{[}0.\+0, 1.\+0\mbox{]}, ma valori fuori da questo range sono validi e causano il wrapping o clamping della texture.
\end{DoxyNote}
