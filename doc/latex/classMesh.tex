\doxysubsection{Detailed Description}
Rappresenta una mesh 3D renderizzabile nella scena. 

Una \doxylink{classMesh}{Mesh} è la rappresentazione di un oggetto tridimensionale composto da\+:
\begin{DoxyItemize}
\item {\bfseries{Geometria}} (\doxylink{classMeshData}{Mesh\+Data})\+: Vertici, facce, normali e coordinate UV
\item {\bfseries{Materiale}}\+: Aspetto visivo della superficie (colori, texture, proprietà)
\item {\bfseries{Proprietà di rendering}}\+: Come la capacità di proiettare ombre
\end{DoxyItemize}

La classe \doxylink{classMesh}{Mesh} eredita da \doxylink{classNode}{Node}, quindi supporta\+:
\begin{DoxyItemize}
\item Trasformazioni gerarchiche (posizione, rotazione, scala)
\item Relazioni parent-\/child nel grafo della scena
\item Priorità di rendering
\end{DoxyItemize}

Caratteristiche principali\+:
\begin{DoxyItemize}
\item Gestione di geometrie complesse attraverso \doxylink{classMeshData}{Mesh\+Data}
\item Supporto per materiali con texture
\item Capacità di proiettare ombre (shadow casting)
\item Modalità di rendering speciale per il color picking
\end{DoxyItemize}

Renderizza la mesh nella scena. 

Questo metodo esegue il rendering completo della mesh\+:
\begin{DoxyEnumerate}
\item Applica il materiale (colori, texture)
\item Applica le trasformazioni (model matrix)
\item Disegna la geometria (vertici e facce)
\end{DoxyEnumerate}

Il comportamento cambia in base alla modalità di rendering\+:
\begin{DoxyItemize}
\item {\bfseries{Modalità normale}}\+: Rendering completo con materiale e illuminazione
\item {\bfseries{Modalità color picking}}\+: Rendering con colori solidi per la selezione
\end{DoxyItemize}

Flag statico per la modalità color picking. 

Quando true, le mesh vengono renderizzate con colori solidi univoci basati sul loro ID, permettendo la selezione degli oggetti tramite il colore del pixel. Utilizzato dal sistema di picking con il mouse.
