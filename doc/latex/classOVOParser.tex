\doxysubsection{Detailed Description}
Parser per il caricamento di grafi di scena da file OVO. 

La classe {\ttfamily \doxylink{classOVOParser}{OVOParser}} fornisce funzionalit{\ucr} per caricare e analizzare i dati delle scene dal formato di file OVO. Converte i dati di questi file in una struttura di grafo di scena composta da nodi, mesh, materiali e luci.\hypertarget{classOVOParser_autotoc_md0}{}\doxysubsubsubsection{\texorpdfstring{Funzionalit{\ucr} principali\+:}{Funzionalit{\ucr} principali\+:}}\label{classOVOParser_autotoc_md0}

\begin{DoxyItemize}
\item Caricamento di un grafo di scena completo da un file OVO.
\item Analisi dei chunk di dati corrispondenti a nodi, mesh, materiali e luci.
\item Estrazione di stringhe dai dati binari.
\item Gestione di una mappa per evitare duplicazioni dei materiali. 
\end{DoxyItemize}

Carica un grafo di scena da un file OVO. 

Carica una scena da un file .ovo e restituisce il nodo root della scena.

Questa funzione legge un file {\ttfamily .ovo} specificato dal percorso {\ttfamily file\+Path}, analizza i dati in esso contenuti e costruisce una struttura di grafo di scena composta da nodi, mesh, luci e materiali.

Questo metodo apre un file .ovo specificato dal percorso {\ttfamily file\+Path}, elabora i dati contenuti nel file e costruisce una gerarchia di nodi che rappresenta la scena. I dati vengono letti in chunk, ognuno dei quali rappresenta un diverso tipo di oggetto nella scena (nodi, materiali, luci e mesh). La gerarchia dei nodi viene costruita utilizzando uno stack per gestire i nodi e il loro conteggio di figli rimanenti.
