\doxysubsection{Detailed Description}
Classe base astratta per tutte le entità del motore grafico. 

La classe \doxylink{classObject}{Object} definisce l\textquotesingle{}interfaccia comune e le proprietà di base per tutti gli oggetti gestiti dal sistema. È una classe astratta che non può essere istanziata direttamente, ma deve essere derivata.

Caratteristiche principali\+:
\begin{DoxyItemize}
\item {\bfseries{Identificazione univoca}}\+: Ogni oggetto riceve automaticamente un ID unico generato tramite un contatore statico
\item {\bfseries{Naming}}\+: Ogni oggetto può avere un nome leggibile per facilitare il debugging e la ricerca nella scena
\item {\bfseries{Tipizzazione}}\+: Un campo tipo permette di identificare la categoria dell\textquotesingle{}oggetto
\item {\bfseries{Interfaccia di rendering}}\+: Definisce il metodo virtuale puro \doxylink{classObject_a641d85cb7641c16c0d8ff4cf81798d52}{render()} che tutte le classi derivate devono implementare
\end{DoxyItemize}

La classe gestisce automaticamente la generazione di ID univoci attraverso un contatore statico incrementale, garantendo che ogni istanza abbia un identificatore unico all\textquotesingle{}interno della sessione.

Resetta il contatore statico degli ID a zero. 

Resetta il generatore di ID a zero.

Riporta il generatore di ID al suo stato iniziale. Questo significa che i prossimi oggetti creati riceveranno ID a partire da 0.

\begin{DoxyWarning}{Warning}
Da utilizzare con estrema cautela! Resettare il contatore mentre esistono oggetti con ID già assegnati può causare conflitti di ID e comportamenti indefiniti.
\end{DoxyWarning}
Casi d\textquotesingle{}uso appropriati\+:
\begin{DoxyItemize}
\item All\textquotesingle{}inizio del programma per inizializzazione pulita
\item Dopo aver svuotato completamente la scena e distrutto tutti gli oggetti
\item Durante il caricamento di un nuovo livello quando si vuole ripartire da zero
\end{DoxyItemize}
