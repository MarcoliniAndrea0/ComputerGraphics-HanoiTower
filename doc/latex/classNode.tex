\doxysubsection{Detailed Description}
Rappresenta un nodo nella gerarchia di una scena 3D (Scene Graph). 

La classe \doxylink{classNode}{Node} è l\textquotesingle{}elemento fondamentale del grafo della scena e fornisce la struttura gerarchica per organizzare gli oggetti 3D. Ogni nodo può avere\+:
\begin{DoxyItemize}
\item Trasformazioni locali (posizione, rotazione, scala)
\item Un nodo padre (parent)
\item Multipli nodi figli (children)
\item Una priorità di rendering
\end{DoxyItemize}

Le trasformazioni sono gestite tramite\+:
\begin{DoxyItemize}
\item Una matrice di base (\+\_\+base\+Matrix)
\item Componenti individuali di trasformazione (posizione, rotazione, scala)
\end{DoxyItemize}

Il sistema supporta trasformazioni gerarchiche\+: le trasformazioni di un nodo vengono moltiplicate con quelle dei suoi antenati per ottenere la posizione finale nello spazio world.

Calcola e restituisce la matrice di trasformazione locale del nodo. 

Restituisce la matrice del modello locale per questo nodo.

La matrice locale combina la matrice di base con le trasformazioni di scala, rotazione e posizione del nodo. Questa matrice trasforma le coordinate dallo spazio del modello allo spazio del parent.

\begin{DoxyReturn}{Returns}
Matrice 4x4 di trasformazione locale
\end{DoxyReturn}
La matrice del modello locale viene calcolata combinando la matrice di base con traslazione, rotazione e scalatura applicate al nodo. Questo metodo viene utilizzato per determinare la posizione finale e l\textquotesingle{}orientamento del nodo nello spazio 3D.

La local\+Matrix viene calcolata nel seguente ordine\+:


\begin{DoxyEnumerate}
\item Base matrix
\item Scale matrix
\item X rotation matrix
\item Y rotation matrix
\item Z rotation matrix
\item Translation matrix
\end{DoxyEnumerate}

La matrice di trasformazione finale viene ottenuta combinando la matrice di traslazione, la matrice di rotazione e la matrice di scalatura, e poi moltiplicando il risultato con la matrice di base.

\begin{DoxyReturn}{Returns}
La matrice locale per questo nodo come {\ttfamily \doxylink{group__core__matrix_gac54cbc572f1349a255fe476ca6a42a7b}{glm\+::mat4}}. 
\end{DoxyReturn}
