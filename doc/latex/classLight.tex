\doxysubsection{Detailed Description}
Classe base astratta per l\textquotesingle{}implementazione delle luci nella scena 3D. 

La classe \doxylink{classLight}{Light} rappresenta una sorgente di luce generica e serve come classe base per derivare tipi specifici di illuminazione come\+:
\begin{DoxyItemize}
\item \doxylink{classDirectionalLight}{Directional\+Light}\+: luce direzionale (es. sole)
\item \doxylink{classPointLight}{Point\+Light}\+: luce puntiforme (es. lampadina)
\item \doxylink{classSpotLight}{Spot\+Light}\+: luce spot/conica (es. torcia)
\end{DoxyItemize}

Caratteristiche principali\+:
\begin{DoxyItemize}
\item {\bfseries{Modello di illuminazione di Phong}}\+: Supporta tre componenti di colore\+:
\begin{DoxyItemize}
\item Ambientale\+: luce diffusa uniforme
\item Diffuso\+: luce che dipende dall\textquotesingle{}angolo della superficie
\item Speculare\+: riflessione brillante sui materiali lucidi
\end{DoxyItemize}
\item {\bfseries{Gestione automatica degli ID}}\+: Ogni luce riceve un ID univoco Open\+GL (GL\+\_\+\+LIGHT0, GL\+\_\+\+LIGHT1, ecc.) per essere utilizzata nel rendering. Open\+GL tradizionalmente supporta un massimo di 8 luci simultanee.
\item {\bfseries{Gerarchia della scena}}\+: Eredita da \doxylink{classNode}{Node}, quindi le luci possono essere posizionate e orientate nella scena come qualsiasi altro oggetto.
\end{DoxyItemize}
